# STM32F103C8T6 USB MSC + WS2812

Прошивка сохраняет поведение USB Mass Storage: устройство имеет VID/PID `C251:1C03`, отображается как диск `STM32x_USB` и содержит динамический `ReadMe.txt`. Одновременно TIM1 CH1 и DMA формируют сигнал для WS2812 на PA8. Шесть эффектов случайно меняются каждые 3 секунды без повтора одного режима подряд.

## Подключение

| STM32F103C8T6 | WS2812 |
|---|---|
| PA8 | DIN через резистор 220–470 Ом |
| GND | GND |

Ленту питать от отдельного стабилизированного источника 5 В. Земли источника и STM32 должны быть общими. Желателен конденсатор 470–1000 мкФ между 5 В и GND у начала ленты. Уровень 3,3 В обычно распознаётся короткой линией, но для надёжной работы с 5-вольтовой лентой рекомендуется преобразователь уровня 74AHCT125/74HCT14.

ST-Link подключается к SWDIO, SWCLK, GND и 3V3 reference. Не подавать одновременно питание от нескольких источников, если схема платы этого не допускает.

## Конфигурация и сборка

Основные параметры пина, яркости и интервала находятся в `include/app_config.h`. Количество LED задаётся при сборке и по умолчанию равно 8:

Длительность одного режима задаётся в миллисекундах константой `EFFECT_INTERVAL_MS`. Например, 5 секунд: `#define EFFECT_INTERVAL_MS 5000U`.

```powershell
.\tools\build.cmd
.\tools\build.cmd -LedCount 60 -BuildDir build-60
```

Обёртки `.cmd` запускают локальные скрипты с `ExecutionPolicy Bypass` только для дочернего процесса PowerShell и не изменяют системную политику выполнения сценариев. Альтернативный разовый запуск: `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build.ps1 -LedCount 16 -BuildDir build-16`.

Результаты: `build/stm32_ws2812.elf`, `.bin` и `.hex`. Зависимость STM32CubeF1 закреплена в `third_party/STM32CubeF1` на v1.8.6.

Проверка сборки для 1, 8 и 60 LED:

```powershell
.\tools\verify.cmd
```

## Безопасная прошивка

Первым делом сохранить гарантированные 64 КБ исходной flash и SHA-256:

```powershell
.\tools\dump_flash.cmd
```

Скрипт прошивки откажется работать, если резервной копии нет:

```powershell
.\tools\flash.cmd
```

Чтобы прошить нестандартный каталог сборки напрямую, без `Copy-Item`:

```powershell
.\tools\flash.cmd -Image .\build-16\stm32_ws2812.bin
```

Восстановление исходной прошивки:

```powershell
.\tools\restore.cmd -Image .\backup\original-YYYYMMDD-HHMMSS.bin
```

Конкретная установленная микросхема сообщила программатору 128 КБ физической flash. Поэтому дополнительно создан `backup/original-full-128k.bin`: исходные нижние 64 КБ объединены с нетронутой верхней половиной flash. Скрипт восстановления принимает оба размера.

## USB-диск

Носитель принимает служебные записи Windows в RAM для совместимости с Mass Storage, но никогда не пишет их во flash. После перезапуска журнал начинается заново. `ReadMe.txt` содержит всю историю текущего запуска: при каждой смене режима в конец добавляется строка `время — режим`. Ёмкость — 8000 записей, примерно 6 часов 40 минут при интервале 3 секунды. Размер файла, который сообщает FAT, увеличивается по мере появления записей. Windows может показывать размер и содержимое, сохранённые при первоначальном монтировании; чтобы получить свежую историю, переподключите USB после запуска. История продолжает записываться и без USB.

WS2812 полностью автономны: USB-кабель и компьютер не требуются. Достаточно подать питание на STM32 и ленту с общей землёй. Ошибка или отсутствие USB не останавливает цикл эффектов.

## Эффекты

- Static
- Hue sweep
- Comet
- Rainbow
- Sparkle
- Breathing

Яркость ограничена `WS2812_MAX_BRIGHTNESS`, чтобы снизить пиковый ток. Для более длинной ленты рассчитать питание отдельно.
